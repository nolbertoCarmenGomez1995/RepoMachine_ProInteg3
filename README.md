# Analítica de Datos y Machine Learning

Este repositorio reúne las dos materias en la rama `main`, cada una en su propia carpeta. Los requisitos, entregas y flujos de trabajo se mantienen separados.

## Proyecto Integrado III

El material vigente de Proyecto Integrado está en [`ProyectoIntegrado/`](ProyectoIntegrado/). Allí se conservan las actividades y entregas de Goodreads, incluida AE3; esa carpeta será la base para continuar con AE4 y el dashboard.

Para consultar cómo ejecutar los notebooks y qué contiene la entrega, revisa [`ProyectoIntegrado/README.md`](ProyectoIntegrado/README.md).

El documento final del proyecto (AE2, AE3 y AE4) está en [`ProyectoIntegrado/AE4/documento/Proyecto_Integrado_Goodreads_documento_final.pdf`](ProyectoIntegrado/AE4/documento/Proyecto_Integrado_Goodreads_documento_final.pdf), y la aplicación de Streamlit en [`ProyectoIntegrado/AE4/app.py`](ProyectoIntegrado/AE4/app.py).

## Machine Learning

El material de Machine Learning está en [`MachineLearning/RepoMachine_ProInteg3/`](MachineLearning/RepoMachine_ProInteg3/): ejercicios sincrónicos, código, pruebas y la actividad de segmentación K-Means. Esta actividad de Machine Learning es distinta de AE3 de Proyecto Integrado, aunque ambas usen Goodreads.

Consulta [`MachineLearning/RepoMachine_ProInteg3/README.md`](MachineLearning/RepoMachine_ProInteg3/README.md) para instrucciones y detalles.

## Material de referencia e histórico

- `Archivo/ProyectoIntegrado_preAE2/` conserva el material antiguo de Proyecto Integrado, separado de las entregas vigentes.


El material histórico queda archivado, no se usa como parte del flujo vigente. No se requiere un `requirements.txt` global: cada materia tiene sus propias dependencias.
